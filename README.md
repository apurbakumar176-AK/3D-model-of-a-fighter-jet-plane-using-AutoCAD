# AutoCAD Mechanical Design Portfolio

A compact showcase of my **AutoCAD 2D & 3D modeling work** completed during industrial training and internship.

## 🚀 Featured Project — Fighter Jet 3D Model

The main project is a **3D fighter jet plane model created in AutoCAD**, developed from 2D profiles into a detailed 3D assembly.

### Key modeling work
- Fuselage created using **POLYLINE + REVOLVE**
- Wings created with **POLYLINE + EXTRUDE**, then mirrored
- Horizontal and vertical stabilizers modeled and positioned
- Missile components modeled using **REVOLVE, EXTRUDE, ROTATE/COPY and UNION**
- Final assembly combined using **UNION**
- Visualized using AutoCAD's **Shades of Gray** style
- Multiple front, rear, top, side and isometric views produced
